📱 NutriLens（ニュートリレンズ）スマホ初期設定＆利用開始マニュアル

NutriLensは、食事の写真を撮影するだけでAIがカロリーや栄養バランス（PFC・ビタミン等）を瞬時に分析・記録する健康管理Webアプリです。

💡 安心・安全ポイント
データやAPIキーはお使いのスマートフォン端末内（ブラウザのローカルストレージ）にのみ保存されるため、1台ごとに完全に独立して、誰でも無料・プライベートに利用可能です。

📋 全体の流れ

  1. 【事前準備】Google Gemini APIキーを無料取得する（約1〜2分）
  2. 【スマホ起動】スマホのChromeブラウザで開き、ホーム画面に追加する
  3. 【初期設定】アプリにAPIキーを登録・保存する

STEP 1: Gemini APIキーを無料取得する

Gemini APIキーは、Googleアカウントがあれば完全無料（Free Tier）で即時発行できます。PC・スマートフォンのどちらからでも取得可能です。

  1. Google AI Studio にアクセスする
    • 以下のリンクを開きます。
      🔗 Google AI Studio APIキー発行ページ
  2. Googleアカウントでログイン
    • 普段お使いのGoogleアカウント（Gmail等）でログインします。
    • ※利用規約等の同意画面が出た場合はチェックを入れて「同意する（Agree / Continue）」を押します。
  3. APIキーを発行・コピーする
    • 画面上の青いボタン 「Create API key」（または「APIキーを作成」）をタップします。
    • プロジェクト選択画面が出た場合は 「Create API key in new project」（新しいプロジェクトで作成）を選択します。
    • 画面に AIzaSy... から始まる英数字のキーが表示されたら、右横の 「Copy（コピー）」 をタップしてコピーしておきます。

STEP 2: スマホのChromeでアプリを起動＆ホーム画面に追加する

スマホのChromeブラウザからアプリを開き、いつでも1タップで起動できるようにホーム画面アイコンを作成します。

1. ChromeでアプリURLを開く

  • スマートフォンの Chromeブラウザ を開きます。
  • 配布された NutriLensのURL をアドレスバーに入力してアクセスします。

2. ホーム画面に追加（アプリ化）

  • Android（Chrome）の場合:
    1. 画面右上の 「︙（3点リーダー）」 メニューをタップします。
    2. メニュー内の 「ホーム画面に追加」（または「アプリをインストール」）をタップします。
    3. 「追加」を押すと、スマホのホーム画面に 「🍱 NutriLens」 のアイコンが追加されます。
  • iPhone（Safari）をご利用の場合:
    1. 画面下部中央の 共有アイコン（四角から上矢印） をタップします。
    2. メニューをスクロールして 「ホーム画面に追加」 をタップします。

STEP 3: NutriLensにAPIキーを設定・保存する

ホーム画面からアプリを起動し、取得したAPIキーを登録します。

  1. API設定画面を開く
    • NutriLens画面の右上にある 「⚙️（歯車アイコン）」（または「APIキー未設定」バッジ）をタップします。
  2. APIキーを貼り付け
    • 「Gemini API Key」の入力欄をタップし、STEP 1 でコピーしたキー（AIzaSy...）をペースト（貼り付け）します。
  3. モデルの確認
    • 「Gemini 2.5 Flash」（または「Gemini 1.5 Flash」）が選択されていることを確認します（高速・高性能かつ無料枠が豊富でおすすめです）。
  4. 設定を保存する
    • 「💾 設定を保存する」 ボタンをタップします。
    • 画面右上のバッジが ✅ APIキー設定済み に切り替われば初期設定完了です！

🍽️ 基本的な使い方

  • 📸 写真で分析: 「カメラで撮影」または「アルバムから選択」で食事写真をアップロードすると、AIがカロリー・PFCバランス（タンパク質・脂質・炭水化物）・詳細な食材栄養素を自動解析して記録します。
  • ✍️ テキスト・間食を手入力: 写真がない場合やプロテイン・飲み物・おやつなどは、テキストで簡単に入力・解析できます。
  • 📊 履歴・推移グラフ・AI専属アドバイザー: 下部メニューから過去の履歴一覧、日別の栄養推移グラフ、AI専属管理栄養士からのパーソナルフィードバックを確認できます。

🔒 セキュリティと費用について（安心ポイント）

  • データはスマホ内のみに保存: APIキーや食事写真は、お使いの端末ブラウザ内（LocalStorage）にのみ安全に保存され、外部の共有サーバーに送られることはありません。
  • 費用は完全無料: Google AI Studioの無料枠（1分あたり約15リクエストまで）の範囲内であれば、個人利用で費用が発生することはありません。
